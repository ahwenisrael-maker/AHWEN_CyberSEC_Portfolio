# Networking

This section documents hands-on networking exercises completed using **Cisco Packet Tracer**.

The projects demonstrate practical understanding of fundamental networking concepts including IP addressing, subnetting, switching, routing, LAN design, network connectivity, and basic network services.

These simulations were completed as part of my cybersecurity training and provide a foundation for understanding how network infrastructure operates and how network design relates to cybersecurity.

---

## Projects

### 1. Routed Multi-Network LAN

A small network consisting of two IP network segments connected through a router.

**Concepts demonstrated:**

* IP addressing

* ICMP connectivity testing

## Networking & Cybersecurity

Networking is a fundamental component of cybersecurity.

Understanding how devices communicate, how networks are segmented, how traffic moves between networks, and how services are exposed provides an important foundation for security activities such as:

* Network reconnaissance
* Vulnerability assessment
* Traffic analysis
* Network segmentation
* Access control
* Security monitoring
* Incident investigation

These projects therefore form part of my broader cybersecurity portfolio and demonstrate the networking foundation supporting my security training.
